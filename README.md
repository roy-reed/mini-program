# 专辑邀请函盲盒小程序

输入希望被称呼的名字，抽取一段专辑副歌与视觉背景，生成写有「诚邀 XXX 收听」的专属音乐视频邀请函。

**当前交付：完整项目方案 v1.0，尚未实现小程序、后台或视频服务。** 方案依据提供的功能流程图，面向产品、设计、研发、乐队及发行团队协作。规划日期：2026-10-17。

## 首版闭环

填写称呼 → 选择专辑活动 → 开盲盒 → 生成音乐视频 → 试听、保存或分享 → 再次进入查看原邀请函。

默认每个微信用户每个专辑活动抽取一次；修改称呼不会改变已抽中的音乐或背景。后台可复用到下一张专辑。首版交付真实 MP4，用户无需录屏。

## 开发边界

原生微信小程序（TypeScript）＋ TypeScript API ＋ PostgreSQL ＋ 独立 FFmpeg 渲染 Worker ＋ 对象存储。后台为独立 Web 管理端；公开 H5 是后续扩展。

本次没有可直接导入微信开发者工具运行的源码。后续实现时才创建 `apps/miniprogram/project.config.json` 等工程文件；不要把本方案仓库当作已完成的小程序导入。
