# 实现任务卡：按依赖逐项完成

读 [AI_START_HERE](../AI_START_HERE.md) 后从状态表选任务。每张卡可以分多轮，但每轮只完成一个明确子单元。下文 `pnpm` 命令是 P01 建立的脚本；业务尚不存在时不得写虚假“通过”。所有任务都要更新实施状态和对应验收证据。

## P00：建立微信与发布条件台账

- **前置／读取**：无；读开发手册第 1 节、发布手册第 1–3 节。
- **产物**：`docs/project-inputs.md` 与 `docs/runtime-versions.md`；登记主体、AppID、域名、基础库、素材和负责人，仅存非敏感状态。
- **执行**：逐项区分已确认、待提供、需管理员操作；先检查实际类目、备案、开发者和体验成员条件，不替用户猜造。
- **验收**：每个待提供项有负责人和影响任务；真实接口需要的条件可定位；无密钥、身份证明或测试密码入库。
- **继续方式**：外部条件不足时标记对应部分 BLOCKED；P01、P02、P04 的独立工作可继续。

## P01：建立能导入的原生工程与构建

- **前置／读取**：无；读工程蓝图和页面清单。
- **产物**：workspace、锁文件、构建脚本、小程序入口／空页面、API／Worker／后台启动入口、开发数据库 Compose、脱敏 env 示例。
- **执行子单元**：先 workspace／静态检查；再 TS→dist 构建；再 app.json／tabBar／组件注册；最后启动脚本和环境禁止项扫描。
- **验收**：`pnpm check`、`pnpm build:mp:dev`；开发者工具导入准确目录并显示占位页面，且明确当前尚无业务；prod 构建遇到占位域名必须失败。
- **禁止遗漏**：小程序包没有 Node／DOM 依赖、AppSecret、媒体母版或 node_modules；src 修改后重建有效，不能靠手改 dist。

## P02：把契约落成类型与数据库

- **前置／读取**：P01；读 OpenAPI、数据接口文档、数据库实施约定和配置 schema。
- **产物**：`packages/contracts` 生成类型、`db/migrations`、repository 基础、测试数据库、`pnpm contract:check` 实际实现。
- **执行子单元**：先机器契约检查与 DTO；再身份／活动表；再邀请函／任务／分享表；再管理员／清理／额度与约束测试。
- **验收**：全新数据库迁移成功、重复执行不重复建表；故意重复用户／活动抽取被数据库拒绝；错误跨邀请函版本引用被拒绝；契约 `$ref` 都可解析。
- **禁止遗漏**：不是把 JSON 存成一个万能大字段；关键所有权、唯一性、状态和时间约束必须落实。

## P03：微信身份与称呼

- **前置／读取**：P00 的真实 AppID 条件、P02；读称呼规则和微信网络／隐私章节。
- **产物**：auth/users API、微信交换适配器、会话存储、内容检查适配器、名字规范化模块、对应测试。
- **执行子单元**：先身份交换和过期；再称呼规范化／审核；再版本冲突与每日额度；最后真微信联调。
- **验收**：真实 code 只在服务端交换；无头像／手机号依赖；两个页面并发登录只执行一次；401 只恢复一次；中文长名／控制字符／emoji／审核失败正确处理。
- **禁止遗漏**：dev mock 不作为真实联调证据；client 传入的 userId／openid 不能决定所有权；不把称呼原文写日志。

## P04：先证明真实视频可生成

- **前置／读取**：P01；读素材规格、渲染管线和真机保存章节。
- **产物**：测试媒体说明、母版处理脚本、文字 PNG 渲染、FFmpeg 参数数组调用、ffprobe 校验和首条成片证据。
- **执行子单元**：先单款 20 秒母版；再短名／长名文字层；再导出和媒体检测；最后 iOS／Android 播放保存验证。
- **验收**：成片独立播放仍包含姓名、背景和音乐；缺字与溢出在生成前被发现；音轨只出现一次；记录单条渲染时间、CPU／内存和文件大小。
- **禁止遗漏**：未经授权不得拿真实乐队音乐作示例；测试音视频要注明来源或自制；没有真机则该子项保持未完成。

## P05：活动、素材与配置发布

- **前置／读取**：P02、P04；读 campaign schema、素材运营文档和发布事务约定。
- **产物**：资产入库／检查、款式预制任务、活动公开／本人接口、发布校验器与不可变快照。
- **执行子单元**：先上传隔离／真实媒体检查；再款式母版；再草稿与发布；最后活动时间状态与页面所需 DTO。
- **验收**：示例 JSON 可作草稿但不可发布；缺少日期、使用范围、真实对象或审批均拒绝；发布后更改权重生成新版本，不能改旧版本。
- **禁止遗漏**：公开 DTO 没有用户信息或未发布素材；HTTP URL 不能由普通用户控制 Worker 去抓取。

## P06：一次抽取、幂等与并发

- **前置／读取**：P03、P05；读抽取事务、OpenAPI 和验收场景 A04／A05。
- **产物**：draw service、幂等 repository、权重纯函数、唯一邀请函创建事务和集成测试。
- **执行子单元**：先权重边界；再原子写 invitation/revision/job；再同键与异键重试；最后 100 并发数据库验证。
- **验收**：同一用户同活动只有一条抽取及首版任务；响应丢失能读回；同键不同 body 为 409；另一用户同活动可以独立抽取。
- **禁止遗漏**：前端动画不决定结果；不把数据库冲突变成“请重新抽一次”；不在数据库锁内调用微信或 FFmpeg。

## P07：Worker 可恢复地完成任务

- **前置／读取**：P04、P06；读 Worker 租约、数据状态和完成事务。
- **产物**：领取／心跳／执行／校验／上传／写回模块，过期租约恢复、退避、孤立文件清理和关停处理。
- **执行子单元**：先单 Worker；再两个 Worker 竞争；再杀进程／超时；最后上传成功但写回失败的恢复。
- **验收**：过期 Worker 无法覆盖新结果；每周期最多三次执行，用户点击不重置预算；ready 前必须已有验证过的对象；离开页面不丢任务。
- **禁止遗漏**：失败不能全部当成临时错误；授权失效／缺字体直接处理；处理过程中不长期持有数据库锁。

## P08：完成原生页面主闭环

- **前置／读取**：P03、P06、P07；读页面规格、微信导航和状态规则。
- **产物**：entry/name/discover/campaign/draw/generation/invitation/me 页面四件套，以及网络／状态组件。
- **执行子单元**：P08a 身份与称呼；P08b 活动和抽取；P08c 生成与回访；P08d 我的和空／错状态。每个子单元单独编译和真机检查。
- **验收**：新用户可生成，老用户恢复同一作品；切后台停止轮询，回来查服务器；生成失败有明确出口；页面没有假百分比和永久 loading。
- **禁止遗漏**：navigateTo 和 switchTab 不能混用；不能用浏览器本地存储代替云端作品；私有页访问他人 id 返回通用无权状态。

## P09：改名与版本切换

- **前置／读取**：P07、P08；读 revision、pending/current 指针和额度规则。
- **产物**：改名更新确认界面、新版本请求、任务完成 CAS 切换、旧分享撤销和旧文件清理计划。
- **执行子单元**：先成功切换；再失败保留旧版；再并发修改／重复请求；最后旧分享和额度释放。
- **验收**：新版本仍为原 variant；同名不消耗额度；最多一个处理中版本；失败旧版本可用；较旧任务不能覆盖较新名字。
- **禁止遗漏**：用户只有修改默认称呼时不能自动重生成所有活动；旧快照不能原地覆盖。

## P10：保存、隐私和分享真机闭环

- **前置／读取**：P00、P08；读微信开发手册第 5–9 节、share API。
- **产物**：privacy service、media-save service、分享令牌接口、只读分享页、撤销入口和双用户真机证据。
- **执行子单元**：先三层相册授权与下载；再启用／关闭分享；再 A→B 打开；最后 B 制作自己的邀请函与非法令牌测试。
- **验收**：视频保存 success 才计数；403 下载不能当视频；A 关闭分享后新访问失败；B 不能修改 A 的作品；权限拒绝有合理退路。
- **禁止遗漏**：不可将 share intent 计为分享成功；普通卡片封面不带姓名；有意公开个人称呼前说明可见范围。

## P11：运营后台与指标

- **前置／读取**：P05、P07；读后台接口、管理员鉴权约定与统计定义。
- **产物**：管理员初始化工具、密码＋TOTP会话、角色权限、活动／素材／款式／发布／任务页面、指标查询和审计。
- **执行子单元**：先鉴权；再素材／活动表单；再预览／发布控制；最后任务排查／指标。首版不实现在线拖拽模板编辑器。
- **验收**：运营能通过表单上线测试活动；editor 无 publish 权限；普通用户令牌不能调用后台；重试／撤回有原因与审计；指标不含称呼或 OpenID。
- **禁止遗漏**：不用硬编码 admin/admin；密码用成熟 Argon2id 实现，TOTP秘密加密；初始化与重置秘密不进 git 或命令行历史。

## P12：删除、到期与权利撤回

- **前置／读取**：P09、P10、P11；读保留策略、权限矩阵和清理任务设计。
- **产物**：用户与作品删除、到期扫描、清理重试、资产撤回传播、备份恢复后的删除重放。
- **执行子单元**：先作品删除；再账户删除；再素材／活动撤回；最后运行中任务竞态和恢复演练。
- **验收**：删除后会话／分享立即失效；正在完成的 Worker 不能复活数据；作品删除不恢复抽取额度；账户删除按既定策略处理重新注册。
- **禁止遗漏**：日志、分析和旧版本也按期限清理；不能承诺远程收回他人已下载视频。

## P13：可运维部署与回归

- **前置／读取**：P08–P12；读容量、部署、监控、全部验收场景。
- **产物**：镜像／部署配置、环境说明、数据库备份恢复记录、告警、健康检查、完整测试报告和成本实测。
- **执行子单元**：先 staging 部署；再核心回归；再负载／故障注入；最后生产配置预检与回滚演练。
- **验收**：自动检查和 20 项 P0均有结果；参考负载下真实延迟／成功率有报告；记录未达标项，不能改目标掩盖结果。
- **禁止遗漏**：数据库不暴露公网；日志不带令牌；后端兼容上一客户端；生产配置不能连测试库或启用 mock。

## P14：体验版与微信提审

- **前置／读取**：P00、P13；逐项执行发布手册第 1–7 节。
- **产物**：`docs/releases/<version>.md`、build manifest、体验版测试记录、提审材料清单和审核状态。
- **执行子单元**：先正式候选包；再体验成员复测；再材料与隐私核对；经授权上传和提交审核。
- **验收**：实际后台能看到对应版本和状态；审核路径可复现；代码、活动、生产配置与说明一致；审核驳回按原始反馈修复。
- **禁止遗漏**：需要管理员扫码／实名时交给有权限的人；未提交只能标“材料已准备”，不能标“审核中”。

## P15：正式发布与运行交接

- **前置／读取**：P14 审核通过；读发布手册第 8–9 节和排障手册。
- **产物**：正式发布记录、普通用户真实验证、15分钟／1小时／24小时观察记录、支持与回滚负责人。
- **执行子单元**：确认发布授权和窗口；正式发布；普通用户全流程；观察并完成交接。
- **验收**：正式用户可访问、生成、保存和分享，且监控／费用／清理正常；证据关联准确版本。
- **禁止遗漏**：审核通过不等于已发布；体验成员可见不等于正式用户可见；不能把更新延迟误诊成数据丢失。
