# 融合评审与最终裁决 v1.2

日期：2026-10-18。输入为仓库 PR #2 的提交 `45ddd015e775575333d8f4d31b0c21d70c04abca`、用户上传的《专辑来信-完整实施方案.md》与 `album-letter-plan.zip`。附件自称 v2 是它自己的版本号；本仓库统一为 v1.2。附件是参考材料，其“决定”“直接照抄”不自动成为本仓库约束。没有运行附件的部署脚本，也没有验证其应用实现。

## 1. 结论

保留原仓库的业务与安全契约，吸收附件的细任务、早期媒体验证、素材交接和人工上线步骤。继续使用现有仓库，不新建 album-letter 仓库，不把两套 SQL、目录、状态枚举和 npm/pnpm 命令混在一起。先完成一条真实视频闭环，再扩充业务与后台。

选择依据是本项目的维护边界，不是对 DeepSeek 或 Grok 做过性能评测。减少模型每次要处理的内容，依赖窄任务、明确输入、真实测试和交叉审查；不通过删除一致性保护来换取代码变短。

## 2. 两份方案的逐项处理

| 议题 | 附件提案 | 本次裁决与理由 |
| --- | --- | --- |
| 原生端 | TS/WXML/WXSS，不依赖 UI 框架 | 采用。编译仍由仓库脚本执行到 dist，开发者工具不二次编译 TS |
| 仓库与后端 | 新仓库、单 server 包、生产 tsx | 不采用。沿用 workspace、API/Worker 独立进程，服务端编译 JS 后运行；降低与现有契约冲突 |
| 版本 | Node 24、PG 16 | 维持 Node 22 LTS、PG 18、Fastify 5、pnpm 10、TS 5。S01 选兼容补丁并锁定，主版本变动需更新决策 |
| 数据设计 | 10 表、revision 兼队列、无发布快照 | 不采用。保留独立任务、不可变发布版本、预留额度和幂等记录；每张表按迁移任务逐项实现 |
| 姓名处理 | NFC、字体检测、PNG overlay | 采用绘制方式；长度维持 1–16 字素簇，不能改为 JS length 或代码点数 |
| 母版 | 只接收设计师成品 | 采用“预先确认母版，再个性化”的原则；首版保留后台音频/背景固定模板预制，避免运营依赖 CLI；不做剪辑器 |
| 运营后台 | CLI 导入＋极简后台 | 保留表单式 Vue 后台，补齐素材列表、款式列表、预览和封面/收听字段；CLI 仅用于测试与运维 |
| 身份 | 明文 OpenID、7 天 JWT | 不采用。2 小时可撤销随机会话；OpenID 加密＋HMAC 索引；不保存微信 session_key |
| 分享 | 明文随机 token、跟随最新成片 | 不采用。哈希存储、绑定 revision、可重放派生；改名成功撤销旧分享，避免旧链接悄悄显示新称呼 |
| 重试 | 每次手动重试清 attempts | 不采用。用户只能唤醒预算内任务；运营新周期增加 generation，尝试对象键永不复用 |
| 删除 | 仅删除全部，级联立即完成 | 保留单作品删除占位和完整账号删除；202 是清理中，不能承诺相册副本或所有存储瞬间消失 |
| 早期验证 | T01/T02 提前验证媒体和手机 | 采用并加强：关闭开发调试和域名豁免的真实 AppID 证据才通过 G1；测试号结果仅作探索 |
| 前端环境 | 根据 envVersion 选择地址 | 使用构建时固定 APP_ENV/API_ORIGIN；同一个 prod 候选包体验、审核、发布连接同一生产后端 |
| 隐私 | 不写回调，保证官方自动弹窗 | 不作为保证。固定实现集中隐私服务及官方按钮绑定的自定义授权组件，真机验证成功/拒绝/销毁流程 |
| 类目/审核 | 默认图片处理、若干固定期限 | 不采用确定结论。真实服务包含音乐播放、视频生成与分享，主体负责人核实允许类目和材料；不靠改文案隐藏业务 |
| 文案 | 大量词绝对禁用以避审 | 使用“拆开邀请函/随机款式”，公开概率、免费无奖品。词语检查是产品文案规则，不是过审保证 |
| 收听入口 | 跳音乐小程序或复制词 | 采用。首版明确无 web-view；未经验证时只展示搜索词，复制由用户点击 |
| 运维 | 可复制 Compose/备份/巡检模板 | 采用步骤思想，重新实现并测试；不直接执行附件模板，不默认公网暴露数据库、不用 latest 发布 |

## 4. 不需要用户再次选择的固定规则

- 用户端没有 H5、web-view、支付、奖品、头像/手机号、用户媒体上传、声音克隆或朋友圈直发功能。
- 一用户一活动一次抽取；同名更新不计次；每天 3 次成功改名、每活动每天 2 次成功姓名合成；失败释放预留，重试不重抽。日期按 Asia/Shanghai。
- 当前文件保留至活动结束后 90 天与素材授权到期的较早者；旧姓名版本最多 7 天；分享最长 30 天、媒体签名最长 300 秒。活动结束不等于立即撤回，权限矩阵见 docs/13。
- 真实视频：720×1280、30fps、H.264/yuv420p、AAC、15–30 秒、faststart，成品上限 15 MiB。任何一个条件失败不能 ready。
- 模型执行按 [精确操作手册](15-model-execution-manual.md) 与 [步骤索引](11-ai-task-cards.md)。账号、合法素材和手机证据不足时可做独立任务，不伪造外部验收。
