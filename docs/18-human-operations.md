# 项目负责人精确操作步骤

H 表示必须有实际账号/设备/权利方的人完成的证据。模型可准备材料和排障，不能代替实名核验、签署或假造审核结果。菜单名称变化时在同一功能入口查找，以账号实际显示为准；每次记录操作日期，不假定某主体一定支持。

## H01：主体、名称与服务范围（现在开始）

1. 打开微信公众平台，确认登录的是目标小程序账号；进入账号基本信息，记录主体类型、公开 AppID、管理员、项目负责人。
2. 把真实功能完整列出：乐队授权音乐试听、带称呼的MP4制作、保存、朋友只读分享。查看服务类目可选项与材料要求，必要时向平台咨询这份实际功能描述。
3. 将后台要求/咨询结果和允许范围记到 `docs/project-inputs.md`，只存去敏结论；没有结论写 BLOCKED，不自行固定为“图片处理”或“音乐”。
4. 确认「专辑来信」可用名称、图标、≤120字符简介和真实服务联系方式。不要用更换文字来掩盖真实功能。

完成证据：主体与AppID一致、类目及所需材料有依据。负责人身份与证件不入仓库。

## H02：认证、备案、域名与开发权限（和编码并行）

1. 在公众平台查看认证/备案各自状态和前置材料；按主体实际流程申请、核验并保存编号/状态/有效期。收到短信或电话按实际期限处理，不使用方案里的固定天数代替通知。
2. 如采用大陆云服务，按接入商流程办理相应域名备案；区分域名备案与小程序备案，两者不互相替代。资源购买按实际预算与权限完成。
3. 绑定开发者和体验成员，开发者登录微信开发者工具，核实能看到正确AppID；记录稳定工具版本与支持基础库基线3.0.0，后续更改留记录。
4. 配置生产/测试 request、downloadFile 等实际使用域名，核对HTTPS证书链和重定向域名。AppSecret只放服务端秘密系统，不贴聊天或git。

完成证据：真实后台状态、域名与权限记录。备案/类目未满足时保持可独立开发项继续，不能说已具备提审或发布资格。

## H03：素材与授权交接（S03 前提供测试素材，发布前提供正式素材）

1. 乐队提供副歌片段、背景、封面、标识、发行日期与曲目名；指定负责人确认试听、服务器合成、保存、分享及存储期限的范围。
2. 提供授权字体文件与许可证；测试阶段可使用来源明确的开放许可字体和自行制作的测试音画，必须标 TEST，不冒充正式素材。
3. 按 docs/05/16 的格式交接；记录源文件hash、权利证明受控引用、允许地域/期限、署名要求和撤回联系人。剪辑师逐款确认音画与姓名安全区。
4. 表单中的“已确认”必须对应实际证明；缺少任意所需范围的素材不能发布。

## H04：G1 早期真机验证（S04 配合）

1. 获得S03的真实20秒MP4、封面和ffprobe报告；确认视频中有测试称呼与音频。
2. 在目标真实AppID后台完成实际用到的隐私声明；上传受控测试媒体，签名地址短期生成，不写入长期公开文档。
3. 按S04导入 `apps/miniprogram` 的测试构建，关闭“不校验合法域名”和手机开发调试豁免；iPhone与Android分别播放、拒绝后再次操作、同意后保存。
4. 在手机相册独立播放，确认画面内有字且有声；将小程序卡片发给第二微信打开，记录是否需要体验成员及运行形态。
5. 填 [真机记录](templates/device-record.md)，失败保留错误码/requestId/buildId。开发调试才成功不能标G1通过。

## H05：素材入库与发布活动（S15–S18、S33 后）

1. 运营后台用独立管理员登录；建草稿，填封面、分享封面、活动/权利/保留日期、收听入口。
2. 上传素材，等待技术检查；发布者确认授权范围；创建音频/背景/字体组合，发起母版预制。
3. 每款查看短中文/长中文/拉丁姓名预览，完整听看，确认固定文案和音轨；批准当前configHash。
4. 设正整数权重，核对公开的款式和概率，总和正确；发布不可变快照。真实用户已有款式不受后续发布影响。
5. 用普通新用户生成一条、保存、重进恢复；素材撤回演练只用测试活动，观察停止签发与队列取消。

## H06：隐私、服务说明与联系入口（正式提审前定稿）

实际处理清单：微信身份在后端、用户称呼、邀请函/版本、分享访问与去敏技术日志；存储服务为实际云供应商。保留期限按docs/05；相册写入仅用户点击保存时；复制搜索词仅用户主动点击。声明用到的能力，不照抄并勾选没有使用的字段。

在平台的用户隐私保护指引入口按实际字段填用途/处理方/权利入口，完成平台要求的状态流程；小程序内《隐私政策》《服务说明》写清主体、联系、处理目的、字段、保留、分享可见范围、撤回和删除。拒绝相册权限不阻断浏览/播放；称呼同意不等于微信隐私授权或系统相册授权。

完成证据：说明版本与后台版本、页面动作一致；首次、已同意、拒绝、离页、系统权限拒绝均真机测过。法律文本按实际经营资料确认，不宣称这份方案是已出具法律意见。

## H07：完整体验验收（G3）

按 S35 测真实动态业务；A账号改名不换款，B从分享页制作自己的，关闭链接后B新访问失败。断网、401、双击、杀进程重进、改名失败保留旧成片、删除/清理、活动结束/撤回分别记录。后台发布新活动不得要求改源码。示例视频成功不替代这些场景。

## H08：生产候选准备（G4）

1. 确认S36–S39部署、隔离恢复、队列与容量证据；真实域名/存储/微信接口/素材就绪，配置无mock。
2. 用批准SHA执行 `pnpm build:mp:prod`，记录buildId、API_ORIGIN、AppID、媒体/契约/数据库版本。
3. 开发者工具导入同一构建，包分析和编译通过后上传；公众平台版本管理中设为体验版，配置体验成员。
4. 正式候选体验版连接生产后端，依docs/10复测。审核与正式发布用这一候选包；代码变动必须重新上传，不临时切换测试后端。

## H09：提审与驳回处理

确认主体/类目/认证/备案/隐私状态满足后台实际条件。打开版本管理的候选版本提交审核，按 [审核材料表](templates/release-record.md) 填版本、路径、演示活动、免费随机规则、授权与联系方式；如发行未开始，用所有用户同样可访问的合法演示活动。

记录审核编号、时间、版本。驳回保存原文与截图去敏摘要；定位功能/素材/资质/隐私具体原因，交对应S卡修，重新构建和提交。调整分享范围时同时处理API、既有token、页面、材料；不能只隐藏按钮。无备案能否提交审核等平台条件按当次后台显示，不预先保证。

## H10：发布与运行交接（G5）

获得G4证据与项目方发布授权后，管理员发布已通过审核的版本；若实际账号支持且适用，使用其分阶段发布能力。记录正式版本、生效时间、回滚责任者；用非开发/非体验成员的普通微信从真实入口完成一条生成、保存与分享。

发布后15分钟/1小时/24小时按docs/10检查。运营接手活动暂停、失败重试、版权撤回、删除处理、备份恢复和告警联系。保存证书/账号/权利到期日期由负责人安排维护，不自动认为已经设置提醒。活动结束按承诺保留与清理；项目注销按平台与备案流程处理。
