## 操作步骤

1. media只签当前ready且授权有效revision，purpose严格枚举
2. 显式consent后创建绑定revision分享，HMAC按key版本派生，DB只存hash
3. 同一邀请函唯一未撤销链接，过期/新建/幂等重放规则固定；关闭不复活
4. 匿名分享只返回受限DTO，日志/分析不带token/URL

## 验收与命令

- 同键重放同路径、旧创建键不能复活撤销；改名成功旧链接无效
- token猜测/越权/过期/撤回拒绝，签名最长300秒
