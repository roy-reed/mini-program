## 操作步骤

1. 删除事务立即封禁访问/撤销session与share，202清理中
2. 单作品留最小抽取占位；全账号清可关联身份，重新注册不保证防重抽
3. cleanup持久领取后事务外删对象，重试/宽限/备份删除清单
4. 按保留期清姓名/版本/日志；旧Worker孤儿对象不复活
