## 操作步骤

1. 用户点击→隐私→当前revision媒体签名→downloadFile→相册保存
2. HTTP200/文件路径/格式检查，单下载任务且签名仅刷新一次
3. 区分拒绝、系统权限、空间不足、离页取消、网络失败
4. 仅save成功发事件；清理本次临时文件，不删别的文件
