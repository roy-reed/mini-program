### 4.2 `copy.ts`（C02）

直接使用 `templates/copy.ts`：导出 `COPY`、类型 `CopyKey`（如 `'draw.title'`）、`fill(template, vars)`、`t(key, vars)`。缺变量或未知 key 时抛错。

### 4.3 `name.ts`（C02）

```ts
export const NAME_MAX = 10
export const RESERVED_WORDS: readonly string[] // 共享和弦、官方、客服、管理员、微信、腾讯
export type NameError = 'EMPTY' | 'TOO_LONG' | 'BAD_CHAR' | 'RESERVED'
export type NameResult = { ok: true; name: string } | { ok: false; error: NameError }
export const NAME_ERROR_KEYS: Record<NameError, CopyKey> // EMPTY → 'name.errEmpty' …
export function normalizeName(raw: string): string
export function validateName(raw: string): NameResult
```

- `normalizeName`：`normalize('NFC')`；把 `•`（U+2022）、`・`（U+30FB）、`‧`（U+2027）换成 `·`（U+00B7）；去首尾空白；连续空白合成一个空格。
- `validateName` 按顺序判断：空 → `EMPTY`；字符数（按 Unicode 码点）> 10 → `TOO_LONG`；不匹配 `/^[\u3400-\u4DBF\u4E00-\u9FFF\uF900-\uFAFFA-Za-z0-9 ·]+$/u` → `BAD_CHAR`；包含保留词（不分大小写）→ `RESERVED`。
- 用例：`'  小明  '` → `小明`；`'阿依古丽•买买提'` → 通过且变成 `·`；`'   '` → EMPTY；10 个汉字通过、11 个 → TOO_LONG；`'小明🎸'`、`'小明!'` → BAD_CHAR；`'共享和弦粉丝'`、`'微信用户'` → RESERVED；`'Tom   Lee'` → `Tom Lee`。

### 4.4 `fit.ts`（C02）

```ts
export function textWidthEm(text: string): number // 中文、全角字符记 1，其余记 0.6
export function fitFontRpx(text: string, maxWidthRpx: number, maxRpx: number, minRpx: number): number
export function buildInviteText(inviteLine: string, name: string): string // fill(inviteLine, { name })
```

- 中文 / 全角范围：`\u3000-\u9FFF`、`\uF900-\uFAFF`、`\uFF00-\uFFEF`。
- `fitFontRpx = clamp(floor(maxWidthRpx / textWidthEm(text)), minRpx, maxRpx)`；空字符串返回 `maxRpx`。
- 用例：`textWidthEm('诚邀 小明 收听') = 7.2`；`fitFontRpx('诚邀 小明 收听', 520, 44, 28) = 44`；10 个汉字称呼时宽 15.2 → 34；很长时 → 28。

### 4.5 `layout.ts`（C02）

```ts
export const PLAYER_MAX_W_RPX = 600
export const PLAYER_MIN_H_RPX = 480
export const RESERVED_H_RPX = 420 // 顶部标题 + 封皮 + 提示 + 底部链接
export interface PlayerLayout { playerWidthRpx: number; playerHeightRpx: number }
export function layoutFor(windowWidthPx: number, windowHeightPx: number): PlayerLayout
```

算法：`hRpx = windowHeightPx × 750 / windowWidthPx`；`w = floor(min(600, (hRpx − 420) × 3/4))`；如果 `w × 4/3 < 480`，`w = 360`；`h = round(w × 4/3)`。参数 ≤ 0 抛 RangeError。
用例：(390, 844) → 600×800；(320, 568) → 600×800；(768, 1024) → 435×580；(1024, 768) → 360×480。

### 4.8 `draw.ts`（C03）

```ts
export type Rng = () => number // 返回 [0, 1)
export interface DrawResult { videoId: string; audioId: string; comboKey: string; drawnAt: number; manifestVersion: number }
export function comboKeyOf(videoId: string, audioId: string): string // `${videoId}__${audioId}`
export function pickWeighted<T extends { weight: number }>(items: readonly T[], rng: Rng): T
export function drawInvitation(manifest: Manifest, rng: Rng, now: number): DrawResult
```

- `pickWeighted`：`r = rng() × 总权重`，按累计权重找第一个 `r < 累计值` 的；`rng()` 返回 ≥ 1 时取最后一个；列表为空或总权重 ≤ 0 抛错。
- `drawInvitation`：**先**用一次 `rng` 抽画面，**再**用一次抽音乐（测试依赖这个顺序）；组合不在清单里抛错。
- 测试：固定序列的 rng 结果确定；`tests/helpers/rng.ts` 里的种子随机数（mulberry32）抽 20000 次 2×2 等权重，每个组合占比 25% ± 2%；权重 3:1 时约 75% ± 2%。

### 4.10 `manifest-check.ts`（C03）

`export function validateManifest(m: Manifest): string[]`，返回问题列表（空数组 = 通过）：
- `version` 为 ≥ 0 的整数；`base` 非空；至少 1 个画面和 1 首音乐；
- id 匹配 `/^[a-z0-9]+(-[a-z0-9]+)*$/` 且不重复；`textColor` 匹配 `/^#[0-9A-Fa-f]{6}$/`；权重 > 0；
- `copy.inviteLine` 含 `{name}`；`0.5 ≤ nameTopPct ≤ 0.9`；`20 ≤ nameMinRpx ≤ nameMaxRpx ≤ 64`；
- 每个「画面 × 音乐」都有组合，键、`videoId`、`audioId` 对得上，没有多余组合；
- `url`、`posterUrl` 以 `base + '/'` 开头；`buildTimeline({ audioMs: playMs, loopMs })` 不抛错；`|durationMs − (playMs + REST_MS)| ≤ 150`。

### 6.1 login（C06）

data：`step: 'loading' | 'agree' | 'name'`、`agreed`、`edit`、`nameValue`、`nameError`、`submitting`。实例字段：`reviewState: 'unknown' | 'pass' | 'fail'`。

```xml
<view class="page">
  <view class="hero">…{{copy.login.title}} / {{copy.login.subtitle}}</view>
  <block wx:if="{{step === 'agree'}}">
    <view class="agree" bindtap="onToggleAgree">
      <view class="checkbox {{agreed ? 'checkbox--on' : ''}}"></view>
      <text>{{copy.login.agreePrefix}}</text>
      <text class="link" catchtap="onOpenTerms">{{copy.login.terms}}</text>
      <text>{{copy.login.and}}</text>
      <text class="link" catchtap="onOpenPrivacy">{{copy.login.privacy}}</text>
    </view>
    <button wx:if="{{agreed}}" class="btn-primary" open-type="agreePrivacyAuthorization"
      bindagreeprivacyauthorization="onAgreePrivacy">{{copy.login.button}}</button>
    <button wx:else class="btn-primary btn-primary--off" bindtap="onNeedAgree">{{copy.login.button}}</button>
  </block>
  <form wx:elif="{{step === 'name'}}" bindsubmit="onSubmit">
    <view class="title">{{edit ? copy.name.editTitle : copy.name.title}}</view>
    <input class="input" type="nickname" name="nickname" value="{{nameValue}}" maxlength="10"
      placeholder="{{copy.name.placeholder}}" bindinput="onNameInput" bindnicknamereview="onNicknameReview" />
    <view class="hint">{{copy.name.hint}}</view>
    <view wx:if="{{nameError}}" class="error">{{nameError}}</view>
    <button class="btn-primary" form-type="submit" loading="{{submitting}}">{{edit ? copy.name.save : copy.name.submit}}</button>
  </form>
</view>
```

- `onLoad(query)`：`edit = query.edit === '1'`。edit 模式：有同意记录 → `step = 'name'` 并预填称呼，否则 `step = 'agree'`。普通模式：`currentEntry()` 为 login → `agree`，name → `name`，其他 → `goEntry()`。
- `onAgreePrivacy`：`saveAgreement(Date.now())` → `step = 'name'`。
- `onNameInput`：更新 `nameValue`，清空错误，`reviewState = 'unknown'`。
- `onNicknameReview(e)`：`e.detail.pass` 为真或 `e.detail.timeout` 为真 → `'pass'`，否则 `'fail'`。
- `onSubmit(e)`：防重复；取值优先 `e.detail.value.nickname`（选微信昵称时 `bindinput` 可能不触发，官方建议用 form 取值[^input]）；等待 `reviewState` 变化最多 `NAME_REVIEW_WAIT_MS`；`'fail'` → 显示 `name.errReview`；再 `validateName`，失败显示对应文案；成功 `saveName` → edit 模式 `wx.navigateBack()`，否则 `goEntry(await currentEntry())`。

### 6.2 draw（C07）

data：`phase: 'idle' | 'zoom' | 'burst'`、`disabled`、`burstMs`。

- `onLoad(query)`：`currentEntry()` 不是 draw 就 `goEntry()`；`query.redraw === '1'` 或 `redraw` 为真时 `wx.showToast({ title: COPY.draw.redrawNotice, icon: 'none', duration: 2500 })`；清单里没有画面或音乐时 `disabled = true` 并 `console.error`。
- `onDraw`（电视和按钮共用）：不是 idle 或 disabled 就返回 → `phase = 'zoom'` → `ZOOM_MS` 后：`drawInvitation(MANIFEST, Math.random, Date.now())` → `saveInvitation()` → `VIBRATE_ON_DRAW` 时 `wx.vibrateShort({ type: 'light' })` → `phase = 'burst'` → `BURST_MS` 后 `wx.redirectTo(urlForEntry({ entry: 'invitation', redraw: false }, { autoOpen: AUTO_OPEN_AFTER_DRAW }))`。
- `onRules`：`wx.showModal({ title: COPY.draw.rules, content: t('draw.rulesBody', { videos, audios }), showCancel: false, confirmText: COPY.common.ok })`。
- wxml：标题 `{{copy.draw.title}}`（在电视外）→ `<tv phase="{{phase}}" label="{{copy.draw.button}}" disabled="{{disabled}}" bind:draw="onDraw" />` → 主按钮 → 「规则说明」链接 → `<burst active="{{phase === 'burst'}}" duration-ms="{{burstMs}}" />`。

### 6.3 invitation（C09）

data：`ready`、`env: 'closed' | 'opening' | 'open' | 'closing'`、`status: 'idle' | 'loading' | 'playing' | 'error'`、`showVideo`、`videoUrl`、`posterUrl`、`toText`、`inviteText`、`nameColor`、`nameFontRpx`、`nameTopPct`、`nameOpacity`、`playerWidthRpx`、`playerHeightRpx`、`showHeader`、`albumTitle`、`releaseText`、`aiNotice`、`envelopeMs`。实例字段：`timeline`、`videoCtx`、`wasPlaying`、定时器。

```xml
<view class="page" wx:if="{{ready}}">
  <view wx:if="{{showHeader}}" class="header">
    <text class="album">{{albumTitle}}</text>
    <text class="release">{{releaseText}}</text>
  </view>
  <envelope state="{{env}}" to-text="{{toText}}" open-hint="{{copy.inv.tapToOpen}}" close-hint="{{copy.inv.tapToClose}}"
    poster-url="{{posterUrl}}" width-rpx="{{playerWidthRpx}}" height-rpx="{{playerHeightRpx}}"
    duration-ms="{{envelopeMs}}" bind:toggle="onToggleEnvelope">
    <view class="player" style="width:{{playerWidthRpx}}rpx;height:{{playerHeightRpx}}rpx">
      <video wx:if="{{showVideo}}" id="player" class="video" src="{{videoUrl}}" poster="{{posterUrl}}" loop
        controls="{{false}}" show-center-play-btn="{{false}}" show-play-btn="{{false}}"
        show-fullscreen-btn="{{false}}" show-progress="{{false}}" enable-progress-gesture="{{false}}"
        object-fit="cover" bindplay="onVideoPlay" bindwaiting="onVideoWaiting"
        binderror="onVideoError" bindtimeupdate="onTimeUpdate"></video>
      <view class="name" style="top:{{nameTopPct * 100}}%;color:{{nameColor}};font-size:{{nameFontRpx}}rpx;opacity:{{nameOpacity}}">{{inviteText}}</view>
      <view wx:if="{{status === 'loading'}}" class="state">{{copy.inv.loading}}</view>
      <view wx:if="{{status === 'error'}}" class="state state--error">
        <text>{{copy.inv.loadFail}}</text>
        <button size="mini" catchtap="onRetry">{{copy.inv.retry}}</button>
      </view>
    </view>
  </envelope>
  <view wx:if="{{aiNotice}}" class="ai">{{copy.inv.aiNotice}}</view>
  <view class="links">
    <text class="link" bindtap="onChangeName">{{copy.inv.changeName}}</text>
    <text class="sep">·</text>
    <text class="link" bindtap="onLegal">{{copy.inv.legal}}</text>
  </view>
</view>
```

- `onLoad(query)`：不是 invitation 就 `goEntry()`；取抽取记录 → 组合 → 画面；`timeline = buildTimeline({ audioMs: combo.playMs, loopMs: combo.loopMs })`；`wx.getWindowInfo()` → `layoutFor()`；`refreshName()`；`showHeader = !MANIFEST.titleBaked`；`releaseText = t('inv.release', { date })`；`aiNotice = video.aiGenerated`；`ready = true`；`query.autoOpen === '1'` 时调用 `open()`。
- `refreshName()`：`inviteText = buildInviteText(MANIFEST.copy.inviteLine, name)`；`toText = t('inv.to', { name })`；`nameFontRpx = fitFontRpx(inviteText, playerWidthRpx − 80, nameMaxRpx, nameMinRpx)`。
- `onToggleEnvelope`：closed → `open()`；open → `close()`；其他状态忽略。
- `open()`：`env = 'opening'` → `ENVELOPE_ANIM_MS` 后 `setData({ env: 'open', showVideo: true, status: 'loading', nameOpacity: 0 }, 回调里 createVideoContext('player', this).play())`。
- `close()`：`videoCtx.stop()` → `setData({ showVideo: false, status: 'idle', nameOpacity: 0, env: 'closing' })` → `ENVELOPE_ANIM_MS` 后 `env = 'closed'`。
- 视频事件：`bindplay` → playing；`bindwaiting` → loading；`binderror` → error（`console.error` 记 `e.detail`）；`bindtimeupdate` → 见 `02` §6，status 不是 playing 时改为 playing。
- `onRetry`：先 `showVideo = false`，回调里再 `showVideo = true`、`status = 'loading'`，重新 `createVideoContext` 并 `play()`。
- `onShow`：`ready` 时 `refreshName()`（修改称呼后返回）；信封开着且离开前在播放 → `play()`。`onHide`：信封开着就记下 `wasPlaying` 并 `pause()`。`onUnload`：清定时器，`stop()`。
- `onChangeName` → `navigateTo('/pages/login/index?edit=1')`；`onLegal` → `navigateTo(PAGES.legal)`。

### 6.4 legal（C10）

- data：`tab: 'terms' | 'privacy'`（`query.tab === 'privacy'` 时默认隐私）、`terms: TERMS`、`privacy: PRIVACY`。
- 两个标签按钮 → 标题、更新日期（`t('legal.updatedAt', { date })`）、分节内容。
- 「查看微信隐私保护指引」→ `wx.openPrivacyContract()`，失败只 `console.warn`。
- 「删除我的数据」→ `wx.showModal` 确认 → `clearAll()` → `wx.showToast({ title: COPY.legal.deleteDone })` → 600ms 后 `wx.reLaunch({ url: PAGES.login })`。
- 不实现 `onShareAppMessage`（转发图标应为灰色）。

## 7. 组件（文字一律由属性传入，组件里不写中文）

### 7.1 `tv`（C07）

- 属性：`phase`（idle / zoom / burst）、`label`、`disabled`。事件：`draw`（idle 且未禁用时点击触发）。
- 结构：两根天线、圆角机身、屏幕（流动渐变 + 扫描线动画，中间显示 `label`）、旋钮、底座。尺寸约 520×420rpx。
- 动画：idle 上下浮动（2.4s 循环）；zoom 放大到 1.15 并抖动（`ZOOM_MS`）；burst 放大到 1.6 并淡出（`BURST_MS`）。

### 7.2 `burst`（C07）

- 属性：`active`、`durationMs`。不拦截点击（`pointer-events: none`），盖满全屏。
- 16 个粒子（角度 `i × 22.5°`，距离 260 / 340rpx 交替，颜色轮流用 `--sc-burst-1…4`）+ 中心白光；`active` 变真时用 CSS 动画飞出并淡出。粒子数据在 `attached()` 里按规则生成（不用随机数）。

### 7.3 `envelope`（C08）

- 属性：`state`、`toText`、`openHint`、`closeHint`、`posterUrl`、`widthRpx`、`heightRpx`、`durationMs`。事件：`toggle`（点信封正面或封皮时触发，组件不自己改状态）。
- 结构：信纸层（`state !== 'open'` 时显示 `posterUrl` 封面图；始终包含 `<slot>`）+ 信封正面（封口三角、“致 {称呼}”、提示文字）。
- 几何：closed 时信封宽 = `widthRpx`、高 ≈ `widthRpx × 0.62`，信纸藏在里面；opening 前 40% 时间封口翻开，后 60% 信纸升起并放大到 `widthRpx × heightRpx`，信封正面下移成播放区下方约 160rpx 的封皮；closing 反向。
- **open 状态下，信纸和它的所有父元素不能有 `transform`**（用 top / left 定位），否则原生视频在部分安卓机上会错位。动画只在 opening / closing 期间使用 transform。
- 时长用 `durationMs` 写进 `transition-duration`。

## 9. 错误与边界

| 情况 | 处理 |
| --- | --- |
| 本机数据读取失败或格式不对 | 当作没有数据，从登录开始 |
| 清单为空（开发期） | 抽取按钮禁用 + `console.error`；precheck 阻止上传 |
| 抽到的组合已下线 | 分流到抽取页并提示重新抽取 |
| 视频加载慢 | 显示封面和“邀请函加载中…” |
| 视频出错 / 断网 | “加载失败，请检查网络后重试” + 重试 |
| 切后台、锁屏、来电 | 暂停；回来继续 |
| 修改称呼 | 返回后立即更新称呼和信封上的“致 {称呼}” |
| 隐私授权被微信要求重新同意 | 分流到登录页协议步骤 |
| 连点抽取 | 只响应第一次 |

## 10. 性能与兼容

- 任何时候页面上最多一个 `<video>`；收起信封就卸载。
- `bindtimeupdate` 里只在透明度变化时 `setData`（0.02 一档）。
- 小程序包里不放大图；总包 < 1.5MB（precheck 检查，上限 2MB）。
- 基础库最低 3.0.0（H02 在后台设置）；iOS、安卓各至少 1 台真机。
- 称呼层用普通 view 覆盖在 video 上（同层渲染）。C05 真机验证；如果某机型称呼被视频盖住，退回用 `cover-view` 包称呼（只改 invitation 页）。
