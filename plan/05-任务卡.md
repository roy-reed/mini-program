## C04 · 素材流水线

- **依赖**：C01、C03
- **允许修改**：`scripts/assets.ts`、`scripts/lib/*.ts`、`tests/ffmpeg-args.test.ts`、`tests/library.test.ts`、`tests/render.int.test.ts`、`miniprogram/data/manifest.ts`（只能由脚本生成）
- **要点**
  1. 命令、参数、输出目录按 `03` §7；参数自己解析（不加依赖）。登记表路径默认 `assets-src/library.json`，sample 内部用 `work/sample/library.json`。
  2. `lib/run.ts`：`spawn` 调 ffmpeg / ffprobe，失败时报出命令和 stderr 末尾；`hasFfmpeg()`。
  3. `lib/library.ts`：解析并校验登记表，返回类型化结果或问题列表（`03` §6 每个字段的规则）。
  4. `lib/probe.ts`：画面时长用帧数 ÷ 30，音乐用 `format=duration`，取整毫秒；图片宽高和 `pix_fmt`。
  5. `lib/ffmpeg-args.ts`：纯函数 `normalizeVideoArgs`、`normalizeAudioArgs`、`renderArgs`、`posterArgs`，按 `02` §5 和 `03` §7；秒数由毫秒换算并保留 3 位小数；淡入淡出、静息时长从 `timeline.ts` 常量来。
  6. `lib/cache.ts`：sha256（输入文件内容 + 参数 JSON），记录在 `work/cache.json`。
  7. `check` 额外检查：叠加图 `pix_fmt` 必须是 `rgba`、`rgba64be`、`ya8`、`ya16be` 之一，否则提示“请导出为 32 位 RGBA PNG”；`title.png` 必须 720×960；源素材时长（考虑 `clip` 和 `pingpong`）在范围内；`album`、`copy` 里没有禁用词（复用 `check-words.ts` 的函数）。
  8. `render` 结束打印表格（组合、时长、大小、份数）和下一步提示：“把 dist-assets/v{n} 上传到 COS 的 shared-chord/ 目录”。
  9. `manifest`：`--base` 必须以 `https://` 开头、末尾不带 `/`；文件头写注释“此文件由 npm run assets -- manifest 生成，请勿手改”；写入前过 `validateManifest`；`titleBaked = overlays.title != null`。
  10. 用 `npm run assets -- sample --base https://example.invalid/shared-chord` 生成清单并提交，后续页面开发有数据可用（H05 会用真实 COS 地址重新生成）。
- **测试**
  - `ffmpeg-args.test.ts`：A = 32400 时滤镜图里有 `setpts=PTS-STARTPTS,fps=30`、`fade=t=out:st=31.400`、`tpad=stop_mode=add:stop_duration=3`（数值可写成 3 或 3.000）、`apad=pad_dur=3`，参数里有 `-t 35.400`、`-movflags +faststart`；没有标题图时不含 `[title]` 且角标输入序号为 2；`aiGenerated: false` 时不加角标；pingpong 时含 `reverse` 和 `concat=n=2`。
  - `library.test.ts`：id 有下划线、缺 `{name}`、权重不等且 `allowUnequalWeights: false`、颜色格式错误都报错；模板 `library.example.json` 结构合法（不检查文件存在）。
  - `render.int.test.ts`（没有 ffmpeg 时 `describe.skip`）：在临时目录用 lavfi 生成 2 秒画面和 12 秒音乐 → render → 时长 15.0 ± 0.1 秒；`blackdetect=d=2.5:pix_th=0.1` 的 black_start 在 [11.5, 12.1]、black_end ≥ 14.9；`silencedetect=n=-50dB:d=2.5` 的 silence_start 在 [11.5, 12.1]；封面 jpg 存在。
- **人工验收**（本机已装 ffmpeg）：`npm run assets -- sample --base https://example.invalid/shared-chord` → `dist-assets/v0/` 有 4 个 MP4 和 4 张 JPG；用播放器打开一个 MP4：开头 1 秒淡入，结尾淡出后 3 秒黑屏无声。
