## 2. Phase 2（Demo 上架后）

**目标**：称呼烧进视频、保存到相册、发给朋友时朋友看到“我的”邀请函、按微信账号一人一份、称呼内容安全检查、运营后台换素材不用发版。

**选型（Q12）**

| 方案 | 优点 | 代价 |
| --- | --- | --- |
| 自建服务器 + 域名 | 灵活；可复用旧包 02–04、07、10 的设计 | 要做域名 ICP 备案（等小程序备案有结果后再提交，避免“主办者冲突”）；要运维 |
| 微信云开发 / 云托管 | 不用自己的域名和 ICP；登录态天然打通 | 绑定微信生态；按量计费；渲染任务要评估时长和内存 |

**要做的事（任选一种方案都需要）**
1. 登录：`wx.login` → 服务端换 openid；Demo 的本机数据首次登录时迁移（称呼、抽到的款式）。
2. 抽取改到服务端，按 openid 一人一份；规则说明不变。
3. 称呼送服务端内容安全检查（`msgSecCheck`）。
4. 渲染队列：复用 `scripts/lib/ffmpeg-args.ts`，在现有滤镜图上加称呼文字层，按“组合体”一起淡入淡出。
5. 素材改私有读 + 签名地址；下载域名加入 downloadFile 合法域名。
6. 保存到相册：`wx.downloadFile` + `wx.saveVideoToPhotosAlbum`，隐私指引补充“相册（仅写入）”。
7. 分享：生成分享 token，朋友打开看到对方的邀请函，再引导领取自己的。
8. 运营后台：上传素材、触发渲染、上下线组合；清单改成接口下发。
9. 数据：`users`、`invitations`（openid、videoId、audioId、称呼、渲染状态、文件地址、分享 token）、`assets`。
10. 改写旧包的 02–04、07、10，按本包格式出新的任务卡。

## 3. 风险

| 编号 | 风险 | 应对 |
| --- | --- | --- |
| R01 | COS 默认域名的视频在真机（关闭调试）播不了 | H06-0 先验；备选 1：把默认域名加进 downloadFile 合法域名；备选 2：COS 绑定已备案的自定义域名（需要 ICP）或改用微信云存储 |
| R02 | “抽取 / 随机”被认为是抽奖 | 规则说明 + 审核备注；备选文案（`06` §8） |
| R03 | 音乐、封面、字体授权或 AI 标识不全 | `03` §10 留档；视频角标 + 页面提示 |
| R04 | AI 画面质量差、不能无缝循环 | `clip` 截取、`pingpong`；人工挑选 |
| R05 | iOS 静音开关下没声音 | `OBEY_MUTE_SWITCH = false`；S11、V5 验证 |
| R06 | 称呼层被原生视频盖住（同层渲染兼容问题） | V2 验证；备选 `cover-view`；open 状态不用 transform |
| R07 | “一人一份”只按设备，删数据或换手机可以重抽 | Demo 接受；Phase 2 按账号 |
| R08 | 小程序包超过 2MB | 素材都在 COS；`precheck` 检查体积 |
| R09 | COS 流量费超预期 | 码率上限 1800k；预算告警；版本目录长期缓存 |
| R10 | 视频被盗链 | 可选：COS 防盗链 Referer 白名单 `servicewechat.com`（开启后必须重测 S22） |
| R11 | 审核、备案时间不可控 | H08 第 1 天提交；审核和备案并行 |
