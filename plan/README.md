# 共享和弦 · 小程序 Demo 方案（Codex 执行版）

> 依据：2026-10-26 会议纪要、《小程序流程1026》PPT（`ref/1026-流程图.png`、`ref/1026-时间轴.png`）。
> 本目录是**唯一需求来源**。Codex 按 `05-任务卡.md` 一张一张写代码；人按 `05` 的人工卡和 `06` 做账号、素材、真机验收和提审。
> 标记说明：【待填】= 需要团队提供的内容，提审前必须填完（`npm run precheck` 会检查）。

## 1. 一句话

用户填一个称呼 → 在「小电视」上抽取一份专属邀请函 → 打开信封，循环播放「随机画面 × 随机音乐」的短片，称呼浮在画面上。

## 2. 本周 Demo 范围

目标：本周内做出可提审的简陋版，跑通「开发 → 体验版 → 提审 → 备案 → 发布」。

**做**
- 登录页：勾选协议 →「微信登录」→ 填称呼（键盘上可一键用微信昵称）。
- 抽取页：小电视载体，点击后放大、炸开，随机确定画面和音乐。
- 邀请函页：信封自动打开并循环播放；称呼随画面淡入淡出；再点封皮收起。
- 协议与隐私页、删除我的数据、右上角转发（转发到登录页）。
- 素材流水线：GIF / 短视频 + 音乐 → 预合成 MP4 → 上传腾讯云 COS → 生成清单。

**不做（留到 Phase 2，见 `07`）**
- 后端、账号体系、服务器、域名、ICP 备案。
- 称呼烧录进视频、保存到相册、分享后朋友看到「我的」邀请函。
- 运营后台、内容安全接口、数据统计。

## 3. 流程总览

```
[登录页 pages/login]
  勾选协议（默认不勾）→「微信登录」→ 填称呼 →「下一步」
        │ 只存本机
        ▼
[抽取页 pages/draw]   “请抽取您的专属邀请函”
  点小电视 / 点击抽取 → 放大 300ms → 炸开 400ms + 轻震动
  随机：画面库抽 1 个 + 音乐库抽 1 首（各自独立）→ 对应一个预合成 MP4
        │
        ▼
[邀请函页 pages/invitation]
  信封「致 {称呼}」→ 自动打开（900ms）→ 循环播放：
  ┌淡入1s┬───── 画面循环 + 音乐 + 称呼 ─────┬淡出1s┬静息3s（黑屏无声）┐→ 回到开头
  轻触封皮 → 收起并停止；再点信封 → 从头播放
```

## 4. 决策表

| 编号 | 决定 | 为什么 | 以后可改 |
| --- | --- | --- | --- |
| D01 | **Demo 无后端**：素材放 COS（公有读），清单打包进小程序，用户数据只存本机 | 本周能做完；不需要服务器、域名和 ICP 备案，只做小程序备案 | Phase 2 加后端（`07` §2） |
| D02 | **「画面 × 音乐」离线预合成 MP4**，称呼在播放时叠加 | 小程序里 GIF 和音乐实时拼接很难对齐、耗性能；称呼每人不同，只能运行时叠加 | Phase 2 服务端把称呼烧进视频 |
| D03 | **时间轴**：以音乐长度为准；开头 1s 淡入，音乐最后 1s 淡出，之后 3s 黑屏无声（静息），整段循环；画面片段重复铺满音乐，最后一份被截断（= 向上取整） | 按 PPT 第 4 页：“最后一个视频仍在播放，但被静息的黑屏覆盖” | 取整方式一个配置项（Q01） |
| D04 | **登录 = 勾选协议 +「微信登录」+ 填称呼**：按钮用 `open-type="agreePrivacyAuthorization"`，称呼框用 `<input type="nickname">` | 不调 `wx.login`，没有服务器也能“登录”；同意隐私授权后，键盘才会出现“用微信昵称” | 按钮文字在 `copy.ts` |
| D05 | **每台设备一份**：抽过就固定；只有该款式下线或删除数据后才重新抽 | 会议“每人一份”；无后端时只能按设备算 | Phase 2 按微信账号 |
| D06 | **画面 3:4 竖版，720×960** | 手机上大、文件小；和信封比例协调 | Q06 |
| D07 | **原生小程序 + TypeScript**，无框架、无 UI 库 | 包小、审核和排错简单，Codex 最稳 | — |
| D08 | **文案集中在 `core/copy.ts`**，提交前自动扫禁用词 | 审核常因“抽奖、测试”等词驳回；集中后好改 | 词表在 `templates/forbidden-words.txt` |
| D09 | **抽取后自动打开信封并播放** | 会议：“点击后直接生成并播放”；播放仍是用户点击的结果 | `config.ts` 开关（Q04） |
| D10 | **打开后再点封皮 = 收起并停止** | 会议：信封“再点封皮关闭”，作为退出机制 | — |

## 6. 名词

| 名词 | 意思 |
| --- | --- |
| 画面 | 视频素材库里的一段可循环动画（GIF 或短视频），流水线会转成 MP4 循环片段 |
| 音乐 | 音频素材库里的一段 10–90 秒音乐片段 |
| 组合 / combo | 一个画面 × 一首音乐，预先合成的一个 MP4，键名 `画面id__音乐id` |
| 称呼 | 用户登录时填写的名字，播放时叠加在画面上 |
| 静息 | 每轮结尾 3 秒黑屏无声 |
| 清单 / manifest | `miniprogram/data/manifest.ts`，记录所有组合的地址和时长 |
| COS | 腾讯云对象存储，放 MP4 和封面图 |
